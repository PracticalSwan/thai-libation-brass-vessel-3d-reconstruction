# Reference-Assisted Presentation Rebuild Plan

Date: 2026-09-06
Status: implemented and verified through the pre-clean stop boundary

## Objective

Create a complete presentation model from project photographs and reviewed masks while preserving the direct Steps 1-17 photogrammetry evidence unchanged. Stop before manual Blender cleaning or sculpting.

## Implementation sequence

1. Recover project state and confirm the existing local dense mesh remains evidence, not editable source geometry.
2. Use reviewed normal-side masks to measure the vessel-set silhouette and external width/height ratio.
3. Sample masked raw photographs to obtain a robust brass color reference.
4. Generate deterministic radial profiles for the receiving bowl, vessel body/neck, and lid.
5. Build closed rotational meshes in Blender with separate finial, bands, relief, and chain-link geometry.
6. Build a metallic brass node material from the photograph color plus controlled procedural roughness and bump.
7. Add repeated decoration only as explicitly disclosed reference-assisted inference.
8. Render front, quarter, side, and top-oblique beauty views.
9. Export `.blend` and `.glb` pre-clean assets.
10. Validate closed/manifold mesh objects and a normalized primary-form silhouette IoU gate.
11. Run focused tests, compilation, the real `--stage all` path, and the complete project suite.
12. Update project documentation and stop before manual Blender cleanup.
