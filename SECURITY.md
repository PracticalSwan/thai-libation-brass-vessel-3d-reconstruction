# Security Policy

This repository is an academic computer-vision project and does not run a public service or production backend.

## Sensitive material

Do not commit API keys, tokens, credentials, private configuration, or personal records. The user has authorized publication of the reviewed raw capture photographs and image-processing evidence; this does not authorize publishing any separate secret or private material that may appear later.

## Reporting a security issue

For a genuine security or privacy issue, contact the repository owner privately through GitHub rather than posting sensitive details in a public issue. Public issues are appropriate for ordinary bugs that do not expose sensitive information.

## Supported code

Security fixes target the current `main` branch. Dependencies should be kept minimal and updated when a relevant compatibility or security reason exists; do not perform unrelated dependency churn.
